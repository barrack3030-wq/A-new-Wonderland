# 邦盖7天7夜行程

如果你希望更从容地探索 **Luwuk 和邦盖群岛**，这条7天7夜私人路线结合了陆路、渡轮、海滩以及较为偏远的海岛目的地，包括 **Paisu Pok、Mbuang-Mbuang、Bontolan、Oyama、Long Beach、Pulo Dua、Kamumu 和 Salodik**。

> 渡轮和海上活动需要根据天气、海况以及当地运营时间进行调整。

## 行程概览

| 天数 | 路线 | 主要体验 | 住宿 |
|---|---|---|---|
| 第1天 | Luwuk → Piala → Salakan | 抵达与渡轮 | Salakan |
| 第2天 | Salakan → Paisu Pok → Paisu Batango → Kawalu → Poganda | 湖泊与海滩 | Salakan |
| 第3天 | Salakan → Tebing → Mbuang-Mbuang → Bontolan | 水母与海岸 | Salakan |
| 第4天 | Salakan → Tebing → Oyama → Long Beach → Bontolan | 海滩与海岸 | Salakan |
| 第5天 | Pompon → Mandel → Salakan → Luwuk | 海滩与返程渡轮 | Luwuk |
| 第6天 | Luwuk → Pulo Dua | 跳岛与浮潜 | Luwuk |
| 第7天 | Luwuk → Kamumu → Salodik → Luwuk | 瀑布 | Luwuk |

## 实用建议

邦盖是一个海岛目的地，岛际交通不像热门旅游地那样固定。建议为渡轮调整、海况和陆路交通预留缓冲时间，并准备现金、饮用水、防晒用品和防水袋。

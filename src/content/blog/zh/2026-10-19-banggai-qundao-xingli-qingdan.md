# 邦盖群岛旅行带什么？实用行李清单

游览卢武克、佩伦岛和邦盖群岛时，行程可能包括陆路交通、乘船转移、游泳停留，以及在商店和服务有限的地方过夜。提前准备合适的物品，可以让旅途更舒适，也避免行李过多。

这份清单可作为基础参考，请根据路线、季节和住宿安排进行调整。

## 必备物品一览

| 物品 | 用途 |
| --- | --- |
| 小型防水袋 | 乘船时保护手机、证件和备用衣物 |
| 印尼盾现金 | 小村庄或小岛可能没有自动取款机，也不一定支持刷卡 |
| 防晒用品 | 热带阳光在海上和海滩都可能很强 |
| 泳衣和速干衣物 | 适合浮潜、游泳和潮湿天气 |
| 可重复使用的水瓶 | 减少一次性塑料；只在饮用水安全时补充 |
| 个人常用药 | 小岛上可能难以买到特定药品 |
| 离线地图和预订信息 | 城镇以外的手机信号可能不稳定 |

## 衣物与鞋子

准备轻便、透气的衣物，并带一套适合参观村庄或接触当地社区时穿着的得体服装。轻薄长袖衫也有助于防晒。将泳衣、速干短裤和备用衣物放在独立防水袋中。

选择湿水后仍然舒适的凉鞋或鞋子。如果行程包括瀑布、不平整的小路或洞穴，请带适合步行的鞋。不要默认所有海滩和观景点都有铺装道路。

## 浮潜和乘船一日游用品

如果更喜欢合适的个人装备，可以自带面镜；另外准备防晒泳衣和速干毛巾。部分运营商会提供浮潜装备，但请提前确认。手机防水套可以派上用场，但重要物品仍应放在可靠的防水袋中。

听从向导指示，出发前了解海况，不要触碰或踩踏珊瑚。如果海流较强或能见度差，应选择更安全的活动。

## 现金、证件与通信

准备足够的印尼盾，用于餐饮、小额购物、当地交通和突发情况。将部分现金分开放置。提前离线保存住宿信息、船班安排和重要联系电话。

带好身份证件及预订所需文件。离开卢武克前下载地图；如果要前往信号较弱的地区，最好把行程告知亲友。长时间转乘时，充电宝也很实用。

## 健康与天气准备

带上防晒霜、驱虫剂、小型急救包、处方药和基本个人护理用品。热带天气变化较快，轻便雨衣或折叠雨披很有用。游泳或乘船被海水打湿后，备用干衣也能派上用场。

不要指望在小岛上一定能买到某种药品。如果有特殊医疗需求，请在离开较大的城镇前准备好所需用品，并就个人需求咨询医疗专业人员。

## 不必带太多的东西

大行李箱在小船上或狭窄的村道上可能不方便。背包或软包通常更容易携带。不需要的贵重物品和电子设备可以留在住宿处，并尽量使用可重复利用的用品，减少一次性垃圾。

## 离开卢武克前的检查清单

- 直接向船运运营商确认船班，因为时间可能变化。
- 确认住宿是否提供毛巾、饮用水和浮潜装备。
- 前往小岛前准备现金并购买必需品。
- 查看海况预报，并向当地运营商询问最新情况。
- 为不同交通方式之间的换乘预留充足时间。

## 常见问题

### 去邦盖群岛需要带现金吗？
建议携带。不同地点的支付方式不同，大城镇以外的取款机和刷卡服务可能有限。

### 需要自带浮潜装备吗？
取决于个人习惯和运营商安排。先确认行程包含什么；如果面镜贴合度很重要，可以自带。

### 可以带行李箱吗？
小型行李箱也许可行，但背包或软包通常更适合乘船和走不平整的道路。

做好简单准备，可以让岛屿之间的旅程更顺利。尽量轻装出行，保护好怕水的物品，并为海况和交通时间的变化留出余地。
